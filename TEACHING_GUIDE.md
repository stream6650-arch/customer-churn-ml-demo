# Teaching Guide

1. Define churn as a business problem.
2. Inspect features and target.
3. Explain train/test split and preprocessing.
4. Compare Logistic Regression and Random Forest.
5. Discuss Precision, Recall, F1 and ROC-AUC.
6. Connect model output to retention actions.

Extension: class imbalance, cross-validation, threshold tuning, XGBoost/LightGBM and SHAP.
